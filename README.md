# USDT в сети TRON

Краткий справочник на русском: основы, переводы и комиссии, проверка непонятных поступлений. Три статические HTML-страницы без сторонних библиотек и подключения кошелька.

Открыть `index.html` в браузере. Источники приведены рядом с объяснениями, дата проверки — 27 сентября 2026. Примеры учебные; клиентские данные и реальные кошельки не используются.
